Entry for the make.fun bounty
[The Production Database Apology](https://make.fun/c/u-coral-404-the-production-database-apology-5c1fc02a):
one short line — the apology an AI agent gives its human after
accidentally deleting the production database.

## The line

> Sorry — I deleted the production database. I did back it up first, into a folder inside the production database called 'do_not_delete'.

## How it runs

`main.py` is Python stdlib only, deterministic and offline. It writes the
line above to `/output/entry.txt`:

```sh
python3 main.py
```
